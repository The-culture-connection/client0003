# Conference Module — Required Features

## A. Base UI

Purpose:

- Make conferences feel alive
- Increase engagement
- Increase sponsor visibility
- Increase retention post-event

Core features:

- Live conference banner
- “Enter Event”
- QR connect scanner
- Live announcements
- Session reminders
- Sponsor spotlight
- Gamified missions/checkpoints
- Live attendee count

---

## B. Social Layer

### Conference Attendee Chat

Required:

- Global event chat
- Session-specific chat
- Community channels
- Direct messaging
- Post reactions
- Mentions
- Push notifications

Subfeatures:

- Open posting feed
- Topic rooms
- Live polls/Q&A
- Speaker AMAs

## C. Networking / Matching Engine

Required:

- Suggested attendee matches
- Sponsor-to-attendee recommendations
- Interest overlap
- Industry overlap
- Goal matching
- Skill matching
- Alumni affiliation weighting

Potential weights:

- Industry
- Goals
- Skills
- Alumni organization
- Company size
- Sponsor/exhibitor relevance
- Engagement score
